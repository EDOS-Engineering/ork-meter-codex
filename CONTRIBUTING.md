# Contributing

Keep output reduction local and deterministic. Add a meaningful regression
case for a demonstrated loss of diagnostic evidence, stale source, status,
recovery, concurrency or privacy. Preserve explicit full/exact reads, ordinary
shell permissions and the platform's strict observation contract.

Run the checks documented in README. Use synthetic fixtures; never commit
real transcripts, raw provider exports, source-bearing runtime artifacts,
credentials, `.local/`, or customer configuration. Do not report byte reduction
as observed billing or quality improvement.

This repository's CI validates local contracts and never deploys or publishes a
release. Customer release/promotion requires the business's normal review.
