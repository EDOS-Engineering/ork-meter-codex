# Status

Use the `report` tool: `status` with the public pairing `reference`, `savings` for local avoided bytes and token estimates, or `audit` for instruction sizes and configured MCP names. CLI alternatives are `meter status --reference REF`, `savings`, and `audit` in the bundled script.

Distinguish browser authorization, a live local receiver, and a recent acknowledged export. Only the export receipt supports a delivery claim; compare capture and receipt timestamps. Missing evidence is unknown. Snapshots are non-additive; reduction estimates are not measured usage or money saved. Audit lists names and sizes, never configuration values or credentials. Explain its reported coverage gaps before recommending context changes.
