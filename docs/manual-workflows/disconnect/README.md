# Disconnect

Stop the user-controlled capture process. On supported Unix hosts use `meter prepare-removal --config CURRENT_CONFIG --output NEW_CANDIDATE` to prepare removal of the exact helper fragment. Review and apply that candidate only if the original is unchanged. On Windows remove only the locally reviewed Ork Meter telemetry entries; preserve unrelated configuration and later edits. Restart Codex.

The account holder revokes the public pairing reference in Ork Meter. After revocation and capture shutdown, run `meter forget --reference REF --confirm-local-removal` in the bundled script. Local removal does not prove remote revocation or delete hosted usage. Disable/uninstall the plugin through Codex when requested; local output artifacts remain until the user removes their private state directory.
